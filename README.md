# Psy Horror

## Description

Type de jeu : Escape Game en VR

Support : Meta Quest 3

Unity version : 6000.2.10f1

Déplacement : Manettes VR

Thème : Ambiance pesante, angoissante

Lieu : Hopital Psychiatrique



## Histoire

Tu incarnes Nicolas, un ancien patient de cet hoptital psychiatrique.
Tu as été transféré il y a quelques années dans un nouvel hopital, mais tu ne t'y sens pas chez toi.
Tu t'es donc sauvé et es retourné dans ton ancien hopital, maintenant complètement abandoné et délabré.
Ton but est de te rendre dans ton ancienne chambre car c'est là que tu te sens à ta place.
